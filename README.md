# Raam Infra Dev - Premium Infrastructure Website

A high-fidelity, cinematic website showcasing global infrastructure excellence with futuristic design and interactive features.

## 🎨 Design Features

### Visual Aesthetic
- **Color Palette**: Deep Navy (#0A1628) background, Slate Grey structural elements, Electric Cyan (#00D9FF) accents
- **Typography**: Inter for body text, Montserrat for headings
- **Theme**: "Global Gateway" meets "Connected Future" - high-tech, sleek, professional

### Key Sections

#### 1. Hero Section
- Full-screen immersive background with real aviation imagery
- Animated gradient overlays and grid patterns
- Parallax scrolling effects
- Prominent branding and call-to-action buttons

#### 2. Three Pillars (Services)
- **Aero-Hubs**: Aviation infrastructure with terminal automation
- **Maritime Gateways**: Deep-water ports and blue-economy sustainability
- **Urban Ecosystems**: 15-minute cities and smart grids
- Each card features:
  - Background images with overlay effects
  - 3D tilt interaction on hover
  - Detailed statistics
  - "Learn More" modals with comprehensive information

#### 3. Impact Dashboard
- Animated metric counters showing:
  - 425M+ Annual Passenger Capacity
  - 45M TEU Cargo Throughput
  - 125K Hectares of Sustainable Urban Living
- Interactive Global Infrastructure Network visualization
- Three view modes:
  - **Global**: Worldwide network overview
  - **Regional**: Regional focus with enhanced animations
  - **Timeline**: Temporal development visualization

#### 4. Digital Twin Explorer
- Interactive project selection interface
- Three featured projects:
  - Dubai Mega Hub (Aviation)
  - Rotterdam Expansion (Maritime)
  - Neo-Seoul District (Urban)
- Real-time metrics display:
  - Operational Status
  - Current Capacity
  - Energy Efficiency
  - Sustainability Score
- Simulated 3D model loading

## 📝 Configuration

### shadcn MCP Setup
The project includes shadcn MCP configuration with React Bits registry for advanced component access:

```json
{
  "registries": {
    "@react-bits": "https://reactbits.dev/r/{name}.json"
  }
}
```

MCP server initialized in `.vscode/mcp.json` for VS Code integration.
